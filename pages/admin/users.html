User Management

Create and manage teacher and student accounts.

Bulk import

Upload a .csv or .xlsx file with a header row (legacy .xls is not supported — save as .xlsx instead). Columns (case-insensitive): fullname, email. Any password column is ignored — a secure temporary password is always generated and emailed to each person automatically. For students, also: class, trade, registration_number (all optional). For teachers, also: subjects (comma-separated, optional).

New user

Students must belong to a class — create one first under Academics if the list is empty.

A secure temporary password will be generated automatically and emailed to this person — they'll be asked to change it and verify their email the first time they sign in.

Your school can have up to 5 admin accounts (including you).

Edit user

Editing updates this account in place — nothing is deleted, so their history (submissions, notes, applications, etc.) is preserved.
